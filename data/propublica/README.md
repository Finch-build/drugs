# ProPublica Rx Inspector public data release

`ndc_fei.csv` is copied unmodified from [propublica/rx-inspector-data](https://github.com/propublica/rx-inspector-data)
(ProPublica, data last updated November 2025). It links product NDCs to FDA Establishment Identifiers (FEIs) and is the
authoritative source of drug → facility links in this app.
